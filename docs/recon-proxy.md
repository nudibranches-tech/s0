**Error:** `Err(e)` (an `aws_sdk_s3::error::SdkError<...>`) → `wrap_sdk_error!(e)` producing an `s3s::S3Error`. `src/error.rs:1-28`:
```rust
macro_rules! wrap_sdk_error {
    ($e:expr) => {{
        use aws_sdk_s3::error::SdkError;
        use aws_sdk_s3::operation::RequestId;
        use s3s::{S3Error, S3ErrorCode};

        let mut err = S3Error::new(S3ErrorCode::InternalError);   // default
        let source = $e;
        tracing::debug!("sdk error: {:?}", source);
        if let SdkError::ServiceError(ref e) = source {           // only ServiceError is mined
            let meta = e.err().meta();
            if let Some(val) = meta.code().and_then(|s| S3ErrorCode::from_bytes(s.as_bytes())) { err.set_code(val); }
            if let Some(val) = meta.message()    { err.set_message(val.to_owned()); }
            if let Some(val) = meta.request_id() { err.set_request_id(val); }
            crate::error::SetStatusCode(&mut err, e).call();       // copies HTTP status
        }
        err.set_source(Box::new(source));                          // original SdkError kept as source
        err
    }};
}
```

Propagation caveats for the gateway:
- Non-`ServiceError` SdkError kinds (`ConstructionFailure`, `DispatchFailure`/connection, `TimeoutError`, `ResponseError`) collapse to a bare **`InternalError`** (500) — code/message/request-id/status default; only `.source` carries detail. Your dispatch layer may want to remap these (e.g. RGW unreachable → 503) rather than surfacing 500.
- On success, only `x-amz-request-id` and `x-amz-id-2` are forwarded; **all other upstream response headers are dropped** except what the `try_from_aws(output)` DTO carries and what `s3s` re-serializes. Error responses forward **no** headers (see TODO).
- Streaming: `GetObjectOutput.body` is `Some(try_from_aws(x.body)?)` = `ByteStream`→`SdkBody`→`s3s::Body`→`StreamingBlob` (lazy, not buffered; `builtin.rs:111-124`). Event streams (`select_object_content`) go through `src/event_stream.rs::from_aws` which wraps `aws_sdk_s3::primitives::event_stream::EventReceiver<SelectObjectContentEventStream, ...>` in a `transform_stream::AsyncStream`, per-event `try_from_aws`, errors via `wrap_sdk_error!` yielded into the stream.
