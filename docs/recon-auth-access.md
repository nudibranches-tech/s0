## 1. `trait S3Auth` (`auth/mod.rs:109`)
Single method. Uses `#[async_trait::async_trait]` (dyn-dispatched; stored as `Box<dyn S3Auth>`).
```rust
#[async_trait::async_trait]
pub trait S3Auth: Send + Sync + 'static {
    async fn get_secret_key(&self, access_key: &str) -> S3Result<SecretKey>;
}
```
- No default body — **one required method**.
- Anonymous/presigned representation is *not* in this trait: `S3Auth` only maps `access_key -> SecretKey`. The signature-verification layer decides presence of credentials; anonymity surfaces later as `Option<Credentials>` on `S3Request`/`S3AccessContext`.
- Convention: return `Err(s3_error!(InvalidAccessKeyId))` when unknown. `SimpleAuth` instead returns `NotSignedUp`.

### `SecretKey` (`auth/secret_key.rs:14`)

Trait impls: `Zeroize` (zeroizes inner), `Drop` (calls `zeroize` — zeroize-on-drop), `ConstantTimeEq` (`ct_eq(&self,&Self)->subtle::Choice`, compares bytes), `From<String>`, `From<Box<str>>`, `From<&str>`, custom `Debug` (redacts to `"[SENSITIVE-SECRET-KEY]"`), `Deserialize` (real — reads a `String`), `Serialize` (redacts to placeholder). **No `PartialEq`/`Eq`/`Hash`** — equality only via `ConstantTimeEq`.

## 2. `trait S3Access` (`access/generated.rs:11`) — **macro-generated**
File header: `//! Auto generated by s3s_codegen::v1::access::codegen`. `#[async_trait::async_trait]`, stored as `Box<dyn S3Access>`. Generic `check` + one hook per S3 op.
```rust
#[async_trait::async_trait]
pub trait S3Access: Send + Sync + 'static {
    async fn check(&self, cx: &mut S3AccessContext<'_>) -> S3Result<()> {
        super::default_check(cx)
    }
    // …99 typed per-op hooks (see §3)…
}
```
`check` is the general gate, invoked **before deserializing op input**. Default delegates to `default_check`.

### `default_check` (`access/mod.rs:112`) — **fail-CLOSED for anonymous**
```rust
pub(crate) fn default_check(cx: &mut S3AccessContext<'_>) -> S3Result<()> {
    match cx.credentials() {
        Some(_) => Ok(()),
        None => Err(s3_error!(AccessDenied, "Signature is required")),
    }
}
```
Allows any authenticated principal; denies anonymous. `pub(crate)` — not callable externally, but reachable via `S3Access::check`'s default (`super::default_check`).

> **Enforcement gotcha (module docs `access/mod.rs:19-29`):** `check`/per-op hooks run **only when an auth provider is set**. `set_access` *without* `set_auth` ⇒ access checks skipped entirely. With auth set, checks run for every request including unsigned/invalid ones, where `credentials()` may be `None`.

## 3. Typed per-op hooks — CLAIM CONFIRMED ✅ (fail-OPEN)
**Claim "all 99 typed per-op hooks default to `Ok(())` (fail-OPEN)" is CONFIRMED.** Counts from `generated.rs` (791 lines): `100` total `async fn` = `1` `check` + **`99` typed hooks**; `198` occurrences of `Ok(())` = 99 hooks × (1 doc line + 1 body). Every hook body is literally `Ok(())`.

Exact signature shape — **`async fn` (async-trait), takes `&mut S3Request<XxxInput>`, returns `S3Result<()>`, default body `Ok(())`**:
```rust
/// Checks whether the CopyObject request has accesses to the resources.
/// This method returns `Ok(())` by default.
async fn copy_object(&self, _req: &mut S3Request<CopyObjectInput>) -> S3Result<()> {
    Ok(())
}
```
The 8 requested representatives (all identical shape, all body `Ok(())`):
```rust

async fn get_object(&self, _req: &mut S3Request<GetObjectInput>) -> S3Result<()> { Ok(()) }          // :394
async fn head_object(&self, _req: &mut S3Request<HeadObjectInput>) -> S3Result<()> { Ok(()) }        // :464
async fn delete_object(&self, _req: &mut S3Request<DeleteObjectInput>) -> S3Result<()> { Ok(()) }    // :198
async fn delete_objects(&self, _req: &mut S3Request<DeleteObjectsInput>) -> S3Result<()> { Ok(()) }  // :212
async fn copy_object(&self, _req: &mut S3Request<CopyObjectInput>) -> S3Result<()> { Ok(()) }        // :47
async fn list_objects_v2(&self, _req: &mut S3Request<ListObjectsV2Input>) -> S3Result<()> { Ok(()) } // :546
async fn post_object(&self, _req: &mut S3Request<PostObjectInput>) -> S3Result<()> { Ok(()) }        // :560  (PostObjectInput exists)
```
Notes:
- **Not `impl Future`** — it is async-trait `async fn` (boxed future under the hood). Method name = snake_case op; type param = `dto::{Op}Input`.
- Hook takes `&mut S3Request<Input>` (can mutate input/extensions/etc.) — unlike `check` which takes `&mut S3AccessContext`. Hooks run **after** deserialization (they have the typed `Input`); `check` runs before.
- **Asymmetry to note for a deny-by-default design:** `check` defaults fail-CLOSED (denies anonymous) but the 99 typed hooks default fail-OPEN (`Ok(())`). Overriding only `check` leaves every typed op allow-by-default; a deny-by-default backstop must override `check` (and/or every hook).

### Design-relevant summary for a deny-by-default authz gateway
- `S3Auth`: implement `get_secret_key` only; it never sees the operation — pure key lookup. Presign/anonymous decisions happen downstream, surfaced as `Option<Credentials>`.
- `S3Access`: **override `check`** for the deny-by-default backstop (its default denies only anonymous, allows any authenticated). Typed hooks are fail-OPEN (`Ok(())`) — override each one you want to gate, or centralize in `check` (runs pre-deserialization, `&mut S3AccessContext`, has `s3_op()`/`s3_path()`/`headers()`/`uri()` but **not** typed input). Typed hooks run post-deserialization with `&mut S3Request<{Op}Input>`.
- Both providers must be registered (`set_auth` **and** `set_access`) or access checks are silently skipped.
